# 跨境物流策略模型作品集

> 个人学习作品集 | 数据分析方向 | 跨境物流与供应链

## 📋 作品集介绍

本作品集围绕跨境电商物流场景，使用纯Excel公式构建了4个核心策略分析模型：

- 📦 **补货策略模型** - 安全库存、EOQ、三色预警
- 🔄 **库存周转策略模型** - 周转率、ABC分类、库龄分析
- ⏱️ **物流时效策略模型** - 全链路时效、综合评分
- 💰 **物流成本策略模型** - 成本分解、批量优化

## 📂 文件结构

```
├── index.html               # 作品集首页（GitHub Pages入口）
├── README.md                # 本文档
└── models/                  # 4个Excel模型文件
    ├── replenishment_strategy.xlsx   # 补货策略模型
    ├── inventory_turnover.xlsx       # 库存周转策略模型
    ├── logistics_leadtime.xlsx       # 物流时效策略模型
```

## 🔧 技术特点

- 纯 Excel 公式构建，无 VBA、无宏
- 所有参数可调，公式透明
- 配三色预警系统（🟢🟡🔴）
- 支持联动计算和敏感度分析
- 数据为模拟学习数据

## 📊 模型规格

| 模型 | 文件大小 | 工作表 | 公式数 | 覆盖维度 |
|------|---------|--------|--------|----------|

| 库存周转 | 66 KB | 5个 | 140个 | 10个SKU + ABC分类 |
| 物流时效 | 39 KB | 5个 | 213个 | 13条头程 + 10条尾程 |

## 📥 使用方法

1. 点击上方在线作品集链接进入展示页面
2. 在每个模型卡片下点击 **"📥 下载模型"** 下载 .xlsx 文件
3. 使用 Microsoft Excel 2016+ 或 WPS 打开
4. 在【参数输入】Sheet 中修改参数，其他Sheet会自动联动更新
